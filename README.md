# GAMEBOX 🎮

Estúdio web para criar pequenos jogos HTML, editar o código e testar em uma prévia jogável.

## Recursos
- Interface responsiva para celular e computador.
- Modelos jogáveis: coletor de moedas, desafio de reflexos e quiz.
- Gerador inicial local baseado na descrição (sem API externa).
- Editor HTML/CSS/JavaScript com execução em iframe isolado.
- Salvar e abrir projetos no armazenamento local do navegador.
- Exportar cada jogo como arquivo HTML independente.

## Executar
Abra `index.html` em um navegador moderno. Não precisa de instalação nem de chave de API.

## Limitações desta versão
Ainda não há geração por IA online, contas, sincronização em nuvem ou publicação individual de jogos em URLs HTTPS. Os projetos ficam no navegador/dispositivo; a exportação gera um arquivo HTML.

## Render
O arquivo `render.yaml` configura o site principal como Static Site. Isso hospeda a plataforma, mas não publica automaticamente cada jogo criado.
